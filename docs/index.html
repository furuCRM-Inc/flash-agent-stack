How it works

Three question types. One API call. Zero hallucination.

Instead of asking an LLM to write an answer, FlashAgent evaluates typed questions against a state object and returns calibrated probabilities — in milliseconds.

🎯

Noul — Binary probability

Is this a critical VIP churn risk?
Returns a calibrated probability 0.0 → 1.0. No text. No hallucination.

🔀

Choice — Routing decision

APPROVE_REFUND · ESCALATE · STANDARD?
Returns the winning option with confidence score and full probability distribution.

📊

Score — Urgency rating

Urgency from 0 to 3?
Returns a weighted score across ordered levels — perfect for priority queues and SLA routing.

API Reference

Jev-compatible. Drop in without changing your code.

The request and response format is identical to TypeSafe AI Jev. Swap the endpoint — everything else stays the same.

Request — POST /v1/systemone 
{
  "model": "flash-local",
  "state": "{\"message\": \"System down. Lost $50,000. Cancel NOW!\", \"tier\": \"Enterprise\"}",
  "questions": {
    "is_critical": {
      "type": "noul",
      "instructions": "Does this require immediate VIP retention intervention?"
    },
    "recommended_action": {
      "type": "choice",
      "instructions": "Select the most appropriate retention action.",
      "criteria": {
        "APPROVE_MAX_REFUND": "Approve full refund immediately",
        "ESCALATE":           "Escalate to senior support team",
        "STANDARD_RESPONSE":  "Route to standard support queue"
      }
    },
    "urgency_level": {
      "type": "score",
      "instructions": "Rate the urgency of this situation.",
      "levels": {
        "0": "Low: No immediate churn risk",
        "1": "Medium: Same-day response",
        "2": "High: Priority within the hour",
        "3": "Critical: High-value customer threatening cancellation"
      }
    }
  }
}
Response — 200 OK 
{
  "model": "flash-local",
  "answers": {
    "is_critical":        { "type": "noul",   "noul": 0.89 },
    "recommended_action": { "type": "choice", "choice": "APPROVE_MAX_REFUND", "confidence": 0.82,
                               "probabilities": { "APPROVE_MAX_REFUND": 0.82, "ESCALATE": 0.13, "STANDARD_RESPONSE": 0.05 } },
    "urgency_level":      { "type": "score",  "score": 2.61, "confidence": 0.74 }
  },
  "usage": { "input_tokens": 312, "output_tokens": 0 }  // output always 0 — no text generated
}
Deploy

Deploy to Cloudflare Workers in 30 seconds

Zero cold starts · 100,000 free requests per day · Global edge network · Workers AI built-in.

1

Clone the repository

git clone https://github.com/furuCRM-Inc/flash-agent-stack
cd flash-agent-stack/apps/backend

2

Install & authenticate

npm install   then   npx wrangler login
A browser window opens. Sign in with your Cloudflare account (free).

3

Deploy to the edge

npm run deploy:cf
Wrangler bundles the Hono app and deploys to Cloudflare's global network. Your URL will be printed: https://flash-agent-stack.<your-account>.workers.dev

4

Connect to Salesforce

Paste your Workers URL into Setup → Named Credentials → FlashAgent_Backend → Endpoint
Also update Setup → Remote Site Settings → FlashAgent_Backend.

5

Deploy the LWC to your Salesforce org

cd apps/salesforce
sf project deploy start --source-dir force-app --target-org <alias>
Drag Flash Agent Demo onto any App Builder page. Done.
